# 3D Models & Visual Assets

- **Curiosity Rover** — [NASA Science: Curiosity 3D Model](https://science.nasa.gov/resource/curiosity-3d-model/), NASA Visualization Technology Applications and Development (VTAD). Original source file `Curiosity_static.glb`: https://assets.science.nasa.gov/content/dam/science/psd/solar/2023/09/c/Curiosity_static.glb. Original mesh geometry is preserved; scale and scene orientation are adjusted for gameplay. This is a static mesh (wheels do not articulate independently)[cite: 7].
- **Atlas V Launch Vehicle** — [NASA Science: Atlas V 501 3D Model](https://science.nasa.gov/resource/atlas-v-501-3d-model/), NASA VTAD. Despite the page title, the official asset link provides `Atlas_V_551.glb`: https://assets.science.nasa.gov/content/dam/science/psd/solar/2023/09/a/Atlas_V_551.glb. The original model contains five solid rocket booster nodes (`solid_01`–`solid_05`). For this mission adaptation, `solid_04` was removed to represent a four-booster configuration, and Juno mission markings were stripped from the flight texture. This is an interactive geometric adaptation of NASA's model, **not an exact CAD reconstruction of AV-028**. Booster placement and fine details are not certified against 541 engineering blueprints. [NASA: MSL Launch Press Kit](https://mars.nasa.gov/internal_resources/822/) confirms the Atlas V 541 configuration: 5-meter payload fairing, four solid rocket boosters, and a single-engine Centaur upper stage[cite: 7].
- **Mars Texture (Flight Phase)** — [NASA 3D Resources: Mars Image Texture](https://science.nasa.gov/3d-resources/mars/), NASA/JPL-Caltech, Viking mosaic processed by USGS. Original asset: https://assets.science.nasa.gov/content/dam/science/cds/3d/resources/image/mars/Mars.jpg. A procedural fallback texture is retained if needed.
- **Earth, Phobos, Hazards, Launch Pad & Descent Stage** — Procedural illustrations rather than NASA imagery or exact engineering CAD models. The close Phobos flyby and asteroid field are fictionalized interactive gameplay episodes[cite: 7]. [NASA Science: Phobos](https://science.nasa.gov/mars/moons/phobos/) serves as the scientific reference for the moon.
- **Libraries & Build Scripts** — Three.js and `GLTFLoader` r170 are licensed under MIT (`assets/THREE-LICENSE.txt`)[cite: 7]. Source scripts for vendor wrappers are stored in `js/*.source.js` and bundled for standard `<script>` tags via `node tools/build-models.cjs`.

*Note: The `*-data.js` files bundle local base64-encoded copies of the GLB assets so the simulation runs reliably offline without external network requests. Public hosting and use of NASA assets do not imply endorsement by NASA.*
